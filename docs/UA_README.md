# Віддалене керування комп'ютером / Курсовий проєкт Django

### Можливості

1. **Виконання команд віддалено**  
   У розділі **Chat** ви можете надсилати команди комп'ютеру, якщо він онлайн (програма запущена).  
   Команди виконуються в консолі, а результат повертається у вигляді текстової відповіді.

2. **Автоматичне закриття певних процесів**  
   У розділі **Programs** можна додати програму до моніторингу.  
   Також можна вказати, до якого комп'ютера відноситься цей процес.  
   У деталях комп'ютера внизу є перемикач **«Monitoring»**, який вмикає/вимикає автоматичне закриття вказаних програм. Можна встановити період перевірки.

3. **Збереження часто використовуваних команд**  
   У розділі **Commands** ви можете створювати детальні описи команд та зберігати їх.  
   Якщо команд багато — доступний зручний пошук за назвою.

## Як користуватися

1. Завантажте ZIP-архів з програмою на комп'ютер, який хочете контролювати.
2. Розпакуйте файли та запустіть програму.
3. Автоматично створиться файл `.env` з назвою комп'ютера та паролем.
4. Зареєструйте комп'ютер на сервері.

### Як встановити власний пароль/ID комп'ютера

1. Відкрийте створений файл `.env`.
2. Замініть пароль та ID.

**Важливо!**  
Якщо змінити лише пароль, а ID комп'ютера (`NAME`) залишити без змін, комп'ютер **не зможе** підключитися до сервера.

Потрібно змінювати **обидва** параметри. При зміні `NAME` у базі даних буде створено **новий** комп'ютер.

Якщо ви не хочете, щоб залишався «примарний» комп'ютер (старий ID лишається в БД, але не використовується), створіть і налаштуйте файл `.env` **до** першого запуску програми (`.exe`).

### Обмеження параметрів `.env`

- **PASSWORD**: Обмежень немає — можна використовувати будь-які символи, цифри та будь-яку довжину.
- **NAME**: Максимум 100 символів.  
  Не обов’язково починати з «Computer», але значення **має бути унікальним**.

### Детальний опис параметрів `.env`

- `NAME` — Унікальний ідентифікатор комп'ютера (ID).
- `URL` — Адреса WebSocket-сервера для підключення (замініть, якщо IP сервера інший).
- `PASSWORD` — Пароль для автентифікації комп'ютера.
